Este projeto foi desenvolvido como parte da minha formação no curso técnico de Tecnologia da Informação do SENAC. O objetivo é apresentar minha trajetória de aprendizado, habilidades desenvolvidas, conhecimentos adquiridos e alguns dos projetos realizados durante o curso.

**Sobre o projeto**

O portfólio foi criado para reunir, em um único ambiente, informações sobre minha formação e meu desenvolvimento na área de Tecnologia da Informação.

Além da apresentação pessoal, o site possui páginas dedicadas às áreas do conhecimento, tendências tecnológicas e projetos desenvolvidos ao longo do curso.

**Tecnologias utilizadas**

As principais tecnologias e ferramentas utilizadas no desenvolvimento foram:

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e personalização visual.
- **JavaScript:** implementação das funcionalidades e interações.
- **Bootstrap 4:** auxílio na construção do layout.
- **LocalStorage:** armazenamento local das mensagens.
- **EmailJS:** integração para envio de notificações por e-mail.

**Funcionalidades**

O projeto conta com diferentes recursos:

- Apresentação pessoal e profissional.
- Exibição de hard skills e soft skills.
- Páginas informativas sobre as quatro áreas do conhecimento.
- Seção dedicada às tendências tecnológicas.
- Galeria com projetos desenvolvidos durante o curso.
- Formulário de contato.
- Armazenamento de mensagens utilizando LocalStorage.
- Integração com EmailJS para envio de notificações.
- Painel administrativo com operações CRUD para gerenciar mensagens.

**Estrutura do projeto**

A organização dos principais arquivos está dividida da seguinte forma:

- `index.html` — página principal do portfólio.
- `estilos.css` — estilos visuais do site.
- `script.js` — funcionalidades e interações da página principal.
- `CH.html` — página de Ciências Humanas.
- `CN.html` — página de Ciências da Natureza.
- `MAT.html` — página de Matemática.
- `LGG.html` — página de Linguagens e suas Tecnologias.
- `admin.html` — painel administrativo.
- `admin.css` — estilos do painel administrativo.
- `admin.js` — gerenciamento das mensagens.
- `imagens/` — diretório com as imagens utilizadas no projeto.

**Aprendizados**

Durante o desenvolvimento deste projeto, pude praticar e aprofundar conhecimentos em:

- Estruturação de páginas com HTML.
- Estilização e organização visual com CSS e Bootstrap.
- Lógica de programação com JavaScript.
- Manipulação e armazenamento de dados com LocalStorage.
- Implementação de operações CRUD.
- Integração com serviços externos por meio do EmailJS.
- Organização de arquivos e estruturação de um projeto web.

**Como executar o projeto**

1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso necessário.
3. Abra a pasta principal do projeto.
4. Execute o arquivo `index.html` em um navegador.
